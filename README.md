# DeepLearningFromScratch

A structured journey through Deep Learning, implementing core concepts, algorithms, and neural network architectures from scratch using Python and NumPy.

## 🎯 Purpose

This repository documents my journey of understanding Deep Learning from first principles.

Instead of relying only on high-level frameworks, I implement important concepts manually to understand what happens internally during training and inference.

## 📚 Topics

The repository will gradually cover:

* Neural Networks
* Perceptrons
* Forward Propagation
* Backpropagation
* Activation Functions
* Loss Functions
* Gradient Descent
* Optimization Algorithms
* Convolutional Neural Networks (CNNs)
* Recurrent Neural Networks (RNNs)
* LSTM
* Attention Mechanisms
* Transformers
* and other Deep Learning concepts

## 🛠️ Technologies

* Python
* NumPy
* Matplotlib
* Pandas
* Scikit-learn
* PyTorch
* Jupyter Notebook

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/DeepLearningFromScratch.git
cd DeepLearningFromScratch
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the environment and install dependencies:

```bash
pip install -r requirements.txt
```

## 📈 Learning Philosophy

The goal of this repository is not simply to make models work.

The goal is to understand:

**Mathematics → Algorithm → Implementation → Experiment → Result**

Each implementation should explain the underlying concept and demonstrate it with a small experiment whenever possible.
